# ソードランド政局録 — Suzerain-jp runtime assets

Exact upstream runtime snapshots for the Japanese character card. Only runtime dependencies and their license/provenance records are published here; no card prompts, worldbooks, account data, API credentials or chat history. All ES module dependencies are archived recursively and imported from local relative paths. The source card inline rendering architecture is retained. See DEPENDENCIES.json and LICENSES.json.
