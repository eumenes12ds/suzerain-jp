# プロンプトの方針

## 内蔵プロンプト

変数更新用 AI に MVU の内蔵プロンプトを使用します。主に Gemini と Claude を想定しています。

## 現在のプリセット

現在のプリセットを送信します。物語を書く指示があると、変数の更新に加えて物語を先へ進め、まだ起きていない出来事まで変数に反映することがあります。

## 別のプリセット

選択した保存済みプリセットのプロンプトを、保存された順序で読み込みます。現在のプリセット自体は切り替えません。画面上の未保存の編集内容は読み込みません。

正規表現は現在の環境のものを使用します。カスタム接続の場合、API アドレス・モデル・Temperature などは MVU の追加解析設定を使います。対象プリセットの追加スクリプトや API 設定は適用しません。
