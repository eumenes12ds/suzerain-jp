# 応答形式

- **チャットメッセージ**：追加機能が不要で、広く利用できます。読み取りの安定性はモデルが書式に従うかに左右されます。
- **ツール呼び出し**：提供元の tools・function calling 対応が必要です。文章の混入を減らせますが、未対応のモデルや中継では失敗することがあります。
- **構造化出力**：OpenAI 互換の response_format.json_schema が必要です。JSON Patch の形式を固定できます。
- **構造化出力（v4 互換）**：response_format.type = json_object のみに対応する提供元向けです。接続先を「カスタム」にした場合のみ使えます。

JSON Schema 対応なら構造化出力を試してください。非対応の場合は v4 互換かチャットメッセージを使い、ツール対応の場合はツール呼び出しも選べます。
